# Intelligent Skill Management Platform

An AI-powered platform designed to help organizations manage intern skills, track learning progress, and efficiently find suitable persons for tasks based on skills.

## Overview

The Intelligent Skill Management Platform enables interns to maintain their skill profiles while allowing mentors/managers to discover suitable candidates for projects using semantic skill matching and AI-driven recommendations.

The system provides secure authentication, role-based access control, skill tracking, learning analytics, and intelligent recommendations to support continuous learning and effective project allocation.

---

## Features

### Authentication & Authorization

* JWT-based Authentication
* Secure Login and Registration
* Role-Based Access Control

  * Intern
  * Mentor

### Intern Features

* Create and manage profile
* Add and update skills
* Track learning activities
* View skill progression
* Receive AI-powered learning recommendations

### Mentor Features

* View intern profiles
* Search interns by skills
* Monitor intern progress
* Allocate interns based on skill requirements

### AI-Powered Features

* Skill-based semantic search
* Intelligent learning recommendations
* Similarity matching using embeddings
* Personalized growth suggestions
